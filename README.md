# 온라인 오목

링크 하나로 친구와 두는 온라인 오목. 가입·설치·서버 비용 없음.

- 주소: https://cheon-jaeryong.github.io/omok/
- 방 만들기 → 초대 링크(`?r=방코드`)를 카톡으로 보내면 어디서든 접속
- 통신: 공개 MQTT 중계 서버 2곳(broker.emqx.io:8084, public.cloud.shiftr.io:443)에 동시에 붙어 판 상태를 맞춤
- 규칙: 일반 룰(3·3 금지, 6목 무효) / 자유 룰(5목 이상 승리)

## 회사 PC용 투명창 (`glass/`)

브라우저는 자기 창을 투명하게 만들 수 없어서, 작은 윈도우 도우미(`glass/omok-glass.ps1`)가 오목을 크롬/엣지 앱 창(`--app=…#glass`)으로 띄우고 그 창의 투명도를 바꿉니다.

- 페이지(`#glass`로 열린 창에서만)에 진하기 슬라이더·📌 항상 위 버튼이 생김 → 값은 창 제목 끝에 폭 0 문자(U+2060 사이 U+200B/U+200C 8비트: 진하기 7비트 + 항상 위 1비트)로 적어 둠 → 도우미가 120ms마다 제목을 읽어 `SetLayeredWindowAttributes`/`HWND_TOPMOST` 적용
- Ctrl+Alt+H 숨기기/보이기, 작업표시줄 버튼 숨김(트레이 아이콘), 창을 닫으면 도우미도 종료, 창 위치 기억(HKCU\Software\OmokGlass)
- 친구용 내려받기: `glass/omok-glass.zip` (로비 하단 “💻 회사 PC용 투명창” 버튼) — `omok-glass.bat` 더블클릭
- 크롬은 한 번도 활성화된 적 없는 창의 ‘항상 위’ 요청을 무시함 → 창을 앞으로 꺼내고, 안 되면 사용자가 클릭할 때 적용
